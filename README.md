# 🧀 جبنة السماء — لعبة هيما فارم

لعبة ترفيه عربية بالكامل (RTL) لهوية **هيما فارم** [himasfarm.com](https://himasfarm.com) —
الجبنة بتقصط من السماء، وسلة بأيدك.. اجمع أكبر كمية قبل ما الوقت يخلص!

## الميكانيك
- سلة تتحرك **بالسحب بالإصبع** (موبايل) أو **أسهم الكيبورد** (كمبيوتر)
- **+10** لكل جبنة تقبضها.. **−5** لكل جبنة تهرب على الأرض (مفيش سالب)
- مدة الجولة **٣٠ ثانية** ثابتة
- **الصعوبة بترتفع مع الوقت**: الجبنة تقصط أسرع وبكثافة أكبر
- **محاولتين بس لكل لاعب** — العداد بيتحفظ في المتصفح حتى بعد إعادة التحميل
- **التسجيل قبل اللعب** (اسم + موبايل مصري)، وبعد الجولة بتتسجل النتيجة والعرض في **جوجل شيت**
- **صف واحد لكل موبايل في الشيت**: المحاولة التانية بتحدّث النتيجة بدل ما تضيف صف جديد
- عروض حسب النتيجة: خصم 5% (180–219) / خصم 10% (220–249) / منتج مجاني (250+) مع كود للنسخ

## التقنيات
| الطبقة | الأداة |

| الإطار | Next.js 16 (App Router, Turbopack) + React 19 |

## التشغيل
```bash

```

## بنية الشغل
- `lib/game.ts` — محرك نقي: منحنيات الصعوبة، النقاط +10/−5، حكم الجولة (بدون React)
- `lib/offers.ts` — باندات العروض وإعدادها من env
- `lib/sound.ts` — مؤثرات Web Audio (قبضة/فشل/فرحة)
- `components/game/CheeseCourt.tsx` — مشهد السماء: جبنة نازلة + سلة متحركة + شريط وقت (كل الفيزيكس RAF)
- `components/game/CheeseGame.tsx` — آلة الحالات (البداية/العد/اللعب/النتيجة) والواجهات
- `app/api/leads/route.ts` — استقبال نتيجة الجولة وتحديث صف اللاعب في جوجل شيت
- `google-sheets/apps-script.gs` — كود Apps Script جاهز للصق في الشيت

## ربط جوجل شيت (تسجيل النتائج)
كل جولة تخلص، الواجهة بتبعت `POST /api/leads` بالاسم والموبايل والنقاط والحكم والعرض وكود العرض، والسيرفر بيسجّل **صف واحد لكل موبايل** بالشكل ده:

`التاريخ | الاسم | الموبايل | النقاط | الحكم | العرض | كود العرض`

لو نفس الموبايل لعب تاني، النتيجة والعرض بيتحدّثوا في نفس الصف (آخر محاولة هي اللي بتتحفظ).

السيرفر بيدعم طريقتين — **Apps Script** ليها الأولوية لو `LEADS_WEBHOOK_URL` متظبط:

### الطريقة ١: Apps Script Web App (الأسهل — من غير Google Cloud)
1. افتح الشيت ← **Extensions ← Apps Script**، والصق كود [`google-sheets/apps-script.gs`](google-sheets/apps-script.gs) كله.
2. **Deploy ← New deployment ← Web app**: Execute as **Me**، Who has access **Anyone** ← Deploy، وانسخ رابط `/exec`.
   - بعد أي تعديل في السكريبت: **Deploy ← Manage deployments ← ✏️ Edit ← Version: New version ← Deploy**.
3. في `.env.local`:
   ```bash
   LEADS_WEBHOOK_URL=<رابط /exec>
   LEADS_WEBHOOK_SECRET=<نفس SHARED_SECRET من السكريبت — اختياري>
   ```
السكريبت بيعمل تاب `Leads` والعناوين لوحده أول مرة.

### الطريقة ٢: Service Account (API مباشر)
1. في Google Cloud Console: فعّل **Google Sheets API** → أنشئ **Service Account** → نزّل **JSON key**.
2. شارك الشيت مع إيميل السيرفس (`...iam.gserviceaccount.com`) بصلاحية **Editor**.
3. حط في `.env.local`:
   ```bash
   GOOGLE_SHEETS_ID=<آيدي الشيت من الرابط>
   GOOGLE_SHEETS_TAB=Leads
   GOOGLE_SERVICE_ACCOUNT_EMAIL=<client_email>
   GOOGLE_PRIVATE_KEY=<private_key كامل، \n بين السطور>
   ```

### ملاحظات
- لو مفيش أي إعداد، السيرفر بيطبع الصف في الكونسول (dry-run) واللعبة بتعرض "وضع الديمو".
- **كل موبايل = صف واحد**؛ آخر نتيجة بتحل محل اللي قبلها في نفس الصف.
- **التوقيت بتوقيت القاهرة** (`Africa/Cairo`) وبيتعامل مع التوقيت الصيفي تلقائيًا.
- **حد المحاولتين بيتتبع في المتصفح** (localStorage) لكل رقم موبايل — مسح بيانات الموقع أو تغيير المتصفح بيرجّع العداد.
