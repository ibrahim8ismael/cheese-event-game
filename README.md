# 🍯 تحدي هيماز فارم

لعبة ترفيه عربية بالكامل (RTL) لهوية **هيماز فارم** [himasfarm.com](https://himasfarm.com) —
العسل والتمر بينزلوا من السماء، وسلة بأيدك.. اجمع أكبر عدد منتجات قبل ما الوقت يخلص!

## الميكانيك
- **شاشة شرح الأول**: إزاي تلعب ونظام النقاط، وزر **«فاهم.. يلا بينا!»** بيوّدي لصفحة التسجيل
- سلة تتحرك **بالسحب بالإصبع** (موبايل) أو **أسهم الكيبورد** (كمبيوتر)
- **+10** لكل منتج يدخل السلة.. **−5** لكل منتج هارط الأرض خارجها (مفيش سالب)
- **القنبلة في السلة = −20**: فجوة بترجع السلة وتفطس النتيجة — لو نزلت على الأرض مفيش حاجة
- مدة الجولة **٣٠ ثانية** ثابتة
- **الصعوبة بترتفع مع الوقت**: المنتجات تنزل أسرع وبكثافة أكبر
- **محاولتين بس لكل لاعب** — العداد بيتحفظ في المتصفح حتى بعد إعادة التحميل، وآخر نتيجة هي اللي بتتحسب
- **التسجيل قبل اللعب** (اسم + موبايل مصري) مع سطر موافقة للتواصل على واتساب
- **بعد الجولة الأولى**: اللاعب يختار **فرصة تانية** أو **«استلم جايزتي»** 🎁 (تحذير واضح: لو جرب تاني هيفقد الجايزة). لو اختار الفرصة التانية، نتيجة المحاولة الأولى **مش بتتبعت للشيت** — النتيجة النهائية بس
- **صف واحد لكل موبايل في الشيت**: أي محاولة جديدة بتحدّث نفس الصف بدل ما تضيف صف جديد
- **الجائزة مش بتظهر على الشاشة**: النتيجة والعرض بيتسجلوا في الشيت، والعرض بيتبعت على **واتساب** رقم اللاعب
- عروض حسب النتيجة: خصم 5% (180–219) / خصم 10% (220–249) / منتج مجاني (250+)

## التقنيات
| الطبقة | الأداة |

| الإطار | Next.js 16 (App Router, Turbopack) + React 19 |


## بنية الشغل
- `lib/game.ts` — محرك نقي: منحنيات الصعوبة، النقاط +10/−5، خصم القنبلة، حكم الجولة (بدون React)
- `lib/offers.ts` — باندات العروض وإعدادها من env
- `lib/sound.ts` — مؤثرات Web Audio (قبضة/فشل/فجوة/فرحة)
- `components/game/FarmCourt.tsx` — مشهد السماء: عسل وتمر وقنابل نازلة + سلة متحركة + شريط وقت (كل الفيزيكس RAF)
- `components/game/FarmGame.tsx` — آلة الحالات (الشرح/التسجيل/العد/اللعب/بين المحاولتين/النتيجة) والواجهات
- `app/api/leads/route.ts` — استقبال نتيجة الجولة وتحديث صف اللاعب في جوجل شيت
- `google-sheets/apps-script.gs` — كود Apps Script جاهز للصق في الشيت

### المتغيرات من env
| المتغير | الافتراضي | الوصف |
| --- | --- | --- |
| `NEXT_PUBLIC_BOMB_PENALTY` | `20` | خصم النقاط لما القنبلة تدخل السلة |
| `NEXT_PUBLIC_BOMB_CHANCE` | `15` | احتمال ظهور القنبلة بالنسبة المئوية (15 = 15% من النزولات) |
| `NEXT_PUBLIC_EVENT_LOCATION_URL` | لينك عنوان الفارم من جوجل مابس | اللوكيشن اللي بيفتحه زر **«استلم هديتك من البوث 📍»** في شاشة النتيجة |

القيم دي `NEXT_PUBLIC` — تغييرها محتاج نشر جديد مش تغيير في الشيت.

## ربط جوجل شيت (تسجيل النتائج)
بعد ما اللاعب يحسم نتيجته (يسجّل المحاولة الأولى أو يخلص الفرصة التانية)، الواجهة بتبعت `POST /api/leads` بالاسم والموبايل والنقاط والحكم والعرض وكود العرض، والسيرفر بيسجّل **صف واحد لكل موبايل** بالشكل ده:

`التاريخ | الاسم | الموبايل | النقاط | الحكم | العرض | كود العرض`

لو نفس الموبايل لعب تاني (في جلسة لاحقة)، النتيجة والعرض بيتحدّثوا في نفس الصف (آخر محاولة هي اللي بتتحفظ).

السيرفر بيدعم طريقتين — **Apps Script** ليها الأولوية لو `LEADS_WEBHOOK_URL` متظبط:

### الطريقة ١: Apps Script Web App (الأسهل — من غير Google Cloud)
1. افتح الشيت ← **Extensions ← Apps Script**، والصق كود [`google-sheets/apps-script.gs`](google-sheets/apps-script.gs) كله.
2. **Deploy ← New deployment ← Web app**: Execute as **Me**، Who has access **Anyone** ← Deploy، وانسخ رابط `/exec`.
   - بعد أي تعديل في السكريبت: **Deploy ← Manage deployments ← ✏️ Edit ← Version: New version ← Deploy**.
3. في `.env.local`:
   ```bash
   LEADS_WEBHOOK_URL=<رابط /exec>
   LEADS_WEBHOOK_SECRET=<نفس SHARED_SECRET من السكريبت — اختياري>
   ```
السكريبت بيعمل تاب `Leads` والعناوين لوحده أول مرة.

### الطريقة ٢: Service Account (API مباشر)
1. في Google Cloud Console: فعّل **Google Sheets API** → أنشئ **Service Account** → نزّل **JSON key**.
2. شارك الشيت مع إيميل السيرفس (`...iam.gserviceaccount.com`) بصلاحية **Editor**.
3. حط في `.env.local`:
   ```bash
   GOOGLE_SHEETS_ID=<آيدي الشيت من الرابط>
   GOOGLE_SHEETS_TAB=Leads
   GOOGLE_SERVICE_ACCOUNT_EMAIL=<client_email>
   GOOGLE_PRIVATE_KEY=<private_key كامل، \n بين السطور>
   ```

### ملاحظات
- لو مفيش أي إعداد، السيرفر بيطبع الصف في الكونسول (dry-run) واللعبة بتعرض "وضع الديمو".
- **كل موبايل = صف واحد**؛ آخر نتيجة بتحل محل اللي قبلها في نفس الصف.
- **لو اللاعب اختار الفرصة التانية، المحاولة الأولى مش بتتبعت خالص** — اللي بيتسجل هو النتيجة النهائية بس. لو رفض الفرصة، نتيجته الأولى هي اللي بتتسجل.
- **التوقيت بتوقيت القاهرة** (`Africa/Cairo`) وبيتعامل مع التوقيت الصيفي تلقائيًا.
- **حد المحاولتين بيتتبع في المتصفح** (localStorage) لكل رقم موبايل — مسح بيانات الموقع أو تغيير المتصفح بيرجّع العداد.
